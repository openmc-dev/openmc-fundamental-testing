# OpenMC 0.16.0 runs

Use the pinned environment and `run_tests.py` at the repository root to create
fresh results here. Existing directories are never overwritten.

The scripts and required model/reference inputs are reused from `0.15.3`;
historical OpenMC statepoints, plots, and PASS results are not copied.
Each completed test records its runtime versions in `run_metadata.json`.

No qualification result is claimed for this release until the tests are rerun
and reviewed. The existing qualification report describes OpenMC 0.15.3.
